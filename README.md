## 先分清三个词：原生 IP、住宅 IP、双 ISP

这三个词常被混着用，实际含义一层比一层深。

**原生 IP** 指由英国本土 ISP 分配、在英国本土广播的地址段，地理位置判定为英国，但属性可能仍挂在机房名下。**住宅 IP** 更进一步，在 IPinfo、IPRisk 这类数据库里显示为"住宅宽带"，归属 Sky、Virgin Media 这类英国家庭宽带运营商，从外部看就像一个普通英国家庭在上网。**双 ISP** 指的是这个 IP 的 ASN 归属同时具备两个 ISP 属性，通常是上游与本地 ISP 并存，被风控系统打成"可疑机房"的概率更低。

丽萨主机这条英国线用的是伦敦机房 + 英国 Sky 天空电讯的 IP 段，全新 A 段、双 ISP 原生住宅属性。Sky 是英国第三大宽带运营商，这个归属对英区平台来说比任何机房段都更"像本地人"。

需要记住的一条判断：**平台风控看的是 IP 属性，不是 ping 值。** 一台 180ms 的机房 IP 机器，在 TikTok 眼里依然是机房；一台 250ms 的住宅 IP 机器，反而是它想看到的普通用户。做英国本土业务时，这个优先级不能反过来。

## 它不适合谁，以及几个真实的坑

**国内直连体验不会好。** 官方明确写了"非大陆直连优化网络，建议中转使用"。三网约 250ms 是欧洲直连的上限，晚高峰普通国际 BGP 的丢包是普遍现象，不独这一家。指望买回来直接刷视频、开视频会议，会失望。

## 直连 250ms 怎么压到 200ms 以内

既然官方自己都建议中转，这段就把成本算清楚。

**方案一：香港或日本中转 + 伦敦落地。** 国内到香港/日本的优质线路（CN2 GIA、AS9929、CMIN2）延迟 30–80ms，中转机到伦敦走国际骨干 150–180ms，整体能压到 **180–220ms**，三网都稳。成本是多一台中转机，市面上的香港 CN2 与美西 9929 入门套餐在 **¥24–¥28/月** 起。也就是说，丽萨基础版 ¥68 + 中转 ¥24，每月约 92 元，换来的是 250ms 降到 200ms 左右、晚高峰不丢包。这笔钱值不值，取决于你是拿它远程办公，还是只是挂个后台任务。

**方案二：Cloudflare Spectrum 或自建 relay（gost、brook）。** 省掉一台机器的钱，但优化效果不如专线中转，且 Cloudflare 对 UDP 和部分协议有限制，得先确认你的业务能不能接受。

**方案三：直接接受 250ms。** 跑爬虫、做数据备份、对接英国本地 API、养号时偶尔登进去改设置，这个延迟完全够用。为了"看起来延迟低"配一台中转机，结果业务根本用不上，是常见的冤枉钱。

顺带一提，丽萨主机建议开启 BBR，这在跨洲长肥管道上对吞吐量的改善比降 ping 更明显，装完系统第一件事就该做。
